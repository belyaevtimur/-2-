# Cargo Dependency Graph Visualizer

CLI-инструмент для построения и визуализации графа зависимостей пакетов Rust (Cargo).
Готовые менеджеры пакетов и библиотеки для получения зависимостей **не используются** —
информация извлекается напрямую из реестра crates.io через HTTP API.

## Возможности
- Конфигурация из JSON-файла
- Получение прямых зависимостей заданной версии пакета
- Построение транзитивного графа (BFS без рекурсии) с учётом максимальной глубины
- Обработка циклических зависимостей
- Тестовый режим (граф из файла)
- Вывод обратных зависимостей
- Визуализация в D2 (SVG) и ASCII-дерево
